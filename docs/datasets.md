# Official dataset setup

No raw datasets are bundled or automatically downloaded. Acquire archives from their owners, retain the original README/license, record archive release and checksum, and extract locally. No Kaggle or synthetic substitute is accepted for research results.

| Dataset | Official source | Local directory |
|---|---|---|
| Gas Pipeline | [Tommy Morris ICS datasets](https://sites.google.com/a/uah.edu/tommy-morris-uah/ics-data-sets), Gas Pipeline/ORNL section | datasets/raw/gas_pipeline/ |
| ToN-IoT | [UNSW TON_IoT](https://research.unsw.edu.au/projects/toniot-datasets) | datasets/raw/ton_iot/ |
| Bot-IoT | [UNSW Bot-IoT](https://research.unsw.edu.au/projects/bot-iot-dataset) | datasets/raw/bot_iot/ |
| SWaT | [SUTD iTrust](https://www.sutd.edu.sg/itrust/), follow testbeds/datasets and access request | datasets/raw/swat/ |

The paper swaps the two UNSW links. The old iTrust dataset URL redirects to the iTrust site. Follow owners' access requirements; do not bypass access controls. The initial implementation did not retrieve data. A later command-validation run successfully retrieved the author-linked Gas Pipeline file; see gas_pipeline_source.json for its URL and SHA256.

Start with Gas Pipeline, then ToN-IoT. Inspect each archive's actual column names before preparing; templates intentionally fail when files or labels are missing. CSV/ARFF/Excel input is supported. Excel requires `pip install openpyxl` (or xlrd for legacy xls). Headerless CSV requires `read_options: {header: null, names: [...]}`. SWaT releases may require skipping initial workbook rows. No filenames or schemas are claimed universal across releases.

For Gas, choose the eight-class **categorized** target from the official schema, exclude all other target columns (binary/specific result), and verify the normal label mapping. The inspected author-linked `gas_final.arff` uses the eight-class target `result`, normal code `0`, and26 numeric predictors; gas_pipeline.yaml now specifies this exact schema and filename. Other releases may use different target names; inspect their documentation. Do not map numeric attack IDs to names without the release documentation. Set `numeric_columns` for numeric fields parsed as strings and `features` to a verified allowlist. The retrieved Gas Pipeline file matches the paper's97,019 samples and26-predictor dimensions, but matching counts alone does not identify the paper's split or prove byte-identical input. Report your counts against Table II rather than silently sampling to match it.

The Gas class mapping has now been verified from the [original Morris–Gao dataset paper](https://link.springer.com/chapter/10.1007/978-3-662-45355-1_5), Table VII, and the owner-linked SCADA report, Table 1: 0 Normal, 1 NMRI, 2 CMRI, 3 MSCI, 4 MPCI, 5 MFCI, 6 DoS, 7 Reconnaissance. Full descriptions, source locations and actual local counts are retained in [gas_class_names.json](latex/evidence/gas_class_names.json). The same paper defines `time` as the query–response interval, not a timestamp: do not use it as a chronological splitting key. Saved numeric labels and historical scores were preserved.

For ToN-IoT use the network traffic collection for the ten-class task, not a telemetry-device subset. Use type as target and remove label (a binary target), IP addresses, timestamps and any release-specific target fields. Specify actual official train/test filenames through `files` and `test_files`; the template glob names are placeholders. Validation is carved only from official training. Do not concatenate an official train file with the same full corpus used for test. A release containing only a full corpus can use explicitly documented stratified/group/chronological partitions by removing `test_files`.

For Bot-IoT use category for the five-class task, exclude attack and subcategory as alternate targets. Official 5% and full-corpus releases differ from Table II; neither is automatically declared equivalent. Identify the ten paper features separately; one-hot encoding can increase feature dimension and must be reported as a deviation.

For SWaT preserve available official partitions. A normal-only anomaly-detection training file cannot train a supervised two-class classifier: this pipeline fails when validation/test contain unseen labels. To reproduce a supervised paper-style experiment, explicitly configure a chronological partition within the labelled attack-operation corpus or another approved supervised split and report the departure from anomaly-detection protocols. The supplied full-corpus template is an implementation decision, not an official split. Timestamp sort requires a parsed sortable timestamp; `time_format` can specify the exact pandas datetime format. Random row splits of time-series sensors may overestimate generalization; prefer chronology or disjoint attack/capture groups and inspect class coverage.

All learned transforms are fitted on training only. Min-Max test values may exceed [0,1]; they are not clipped using test extrema. Gas column-L2 uses training-column norms; `row_l2` is an available ambiguity ablation. Raw labels are not imputed. Unknown test classes fail. Unknown feature categories are ignored by one-hot encoding. Split row IDs, SHA256 file digests, class counts, feature names and duplicate-overlap diagnostics are saved. Exact duplicate overlap is reported without silently editing official splits; resolve overlapping capture groups before interpreting results. Shared-content or temporal dependence cannot be ruled out by row-ID disjointness alone.

Saved `preprocessor.joblib` can be reused with `transform_new` in `src.data.preprocessing`. Treat these local pickle artifacts as trusted experiment files. Processed metadata fingerprints scope evaluation caches. Changing the data config or source bytes produces a new fingerprint; use a fresh output directory when preprocessing changes.

User-requested generated profiles are stored separately in `datasets/synthetic/`. They are schema-inspired stochastic fixtures, not replacements for official datasets. See [synthetic generation and tests](synthetic_dataset_validation.md); the original-source configurations continue to require real files.
